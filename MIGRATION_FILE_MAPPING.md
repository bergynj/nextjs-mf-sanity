### Root Configuration Files
```
package.json                    → package.json (update for monorepo)
tsconfig.json                   → tsconfig.base.json (base config)
                                 → apps/web/tsconfig.json (app-specific)
                                 → libs/*/tsconfig.json (library-specific)
tailwindcss.d.ts                → tailwindcss.d.ts (keep at root)
postcss.config.mjs              → postcss.config.mjs (keep at root)
components.json                 → components.json (keep at root or move to ui lib)
```

## Generated Files (Keep at Root)
```
sanity.types.ts                 → Keep at root (generated by typegen)
schema.json                     → Keep at root (generated by schema extract)
```

## Import Path Updates

### Before (Current)
```typescript
import { cn } from "@/lib/utils";
import { client } from "@/sanity/lib/client";
import Button from "@/components/ui/button";
import Hero1 from "@/components/blocks/hero/hero-1";
```

### After (Monorepo)
```typescript
import { cn } from "@schema-ui/shared";
import { client } from "@schema-ui/sanity";
import { Button } from "@schema-ui/ui";
import { Hero1 } from "@schema-ui/blocks";
```
